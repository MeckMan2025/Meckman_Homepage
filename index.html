Business Barometer

Economic health dashboard for Agriculture, Earth Moving, and Property Care

Business Barometer is a white-label economic health dashboard that monitors U.S. market conditions across Agriculture, Earth Moving, and Property Care segments. Powered by live FRED and NOAA federal data, it delivers composite health scores, signal alerts, and indicator trend analysis to help executives make informed decisions.

Weather Dashboard

Real-time weather monitoring and radar data

Weather Dashboard is a responsive web application that displays current weather conditions and live radar data for any city or ZIP code. Simply enter a location to view temperature, weather details, and an interactive precipitation radar map.

Hand Tracker

Computer vision and skeletal tracking for hand detection

Hand Tracker uses the forward-facing camera on a laptop and smart phone to demonstrate computer vision and skeletal tracking for hand detection. Real-time analysis captures hand movements and joint positions, showcasing the capabilities of machine learning in web applications.

Finance Teacher

Interactive finance learning with real market data

Finance Teacher is a visual web-based learning app that helps people understand company performance and valuation. Enter any stock ticker to explore four educational charts: price history, fundamentals, price to earnings ratios, and return on equity trends.

Remi

STEM-focused AI assistant with voice integration

Remi is a charming STEM-focused AI assistant with voice input/output capabilities and "Deep Dig Mode" for detailed analysis. Built with Cloudflare Workers and LLaMA models, featuring a clean, accessible dark UI for an optimal user experience.

Meckman Bot

AI chat and image generation assistant

Meckman Bot is an AI-powered assistant with two modes: chat for conversational Q&A and image mode for generating pictures from text prompts. Built with Cloudflare Workers AI and Flux, it features layered content safety filtering to keep all interactions safe for work and school.

DailyFunnyCat

AI-generated funny cat images delivered daily via MMS

DailyFunnyCat generates a unique AI cat image every morning at 7:00 AM EST and delivers it straight to your phone via MMS. Built with Cloudflare Workers AI (Stable Diffusion XL Lightning), R2 storage, and Twilio for message delivery.

🎬

CatVids

Daily AI-generated cat comedy videos with dialogue

CatVids generates a new AI cat comedy video every morning at 7:00 AM EST featuring talking cats in hilarious scenarios — from corporate meetings to banjo sessions on the porch. Built with Google Veo 3.1 for video generation with synchronized speech and sound, Cloudflare Workers, and R2 storage. 30 unique episodes on rotation.

Everything That's Scrum

Organized scrum board for robotics team collaboration

Everything That's Scrum is a scrum board app built for a 25-person robotics team. It matches tasks to members based on skills and interests, tracks progress through a visual workflow, and supports anonymous questions so no one gets left out. Built with React and Supabase.

MECKMAN: The Platformer

3D platformer starring a real 3D-scanned character

MECKMAN: The Platformer is a browser-based 3D platformer built with Three.js, featuring a Meshy AI full-body scan as the playable character. Run, jump, and collect coins across 5 areas including moving platforms, spinning obstacles, and a spiral tower finale. Supports desktop keyboard/mouse and mobile touch controls with a virtual joystick.

Rover_1

An autonomous rover for waypoint following

Rover_1 is a fully autonomous rover engineered for precise waypoint navigation. By combining IMU fusion, mecanum kinematics, and predictive motion control, it delivers smooth, adaptive movement and demonstrates advanced path-tracking capability in a compact robotic platform.
